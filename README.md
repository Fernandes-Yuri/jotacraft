# JoaoCraft

Jogo voxel de aventura para Android, feito para o Jota jogar com a familia.

- Botao de microfone: fale em portugues e o assistente obedece
- Assistente que conversa, lembra das suas coisas favoritas e controla o jogo
- Funciona offline depois de baixar as vozes uma vez

## Jogar

Instale o APK `arm64-joaocraft.apk` (Actions do GitHub) e conecte no
servidor da familia. Divirta-se!
